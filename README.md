# EcoBairro — Reciclagem e Coleta Seletiva

Projeto desenvolvido na disciplina Programação Web Front-End,
utilizando HTML e CSS, sem frameworks.

## Integrante

Nicollas Berti

## Objetivo

Orientar moradores sobre a separação de papel, plástico, vidro
e metal, incentivando a reciclagem e o descarte adequado dos resíduos.

## Público-alvo

Moradores interessados em aprender sobre coleta seletiva
e contribuir para uma comunidade mais sustentável.

## ODS atendido

ODS 12 — Consumo e Produção Responsáveis.

O projeto se relaciona à meta 12.5, que aborda a redução
da geração de resíduos, a reciclagem e o reúso.

## Páginas

- Página principal: apresentação, materiais recicláveis e ODS.
- Cadastro: formulário com cinco campos obrigatórios.
- Login: formulário com e-mail e senha.
- Currículo: informações do desenvolvedor, acessíveis pelo rodapé.

Cadastro e login são demonstrações de interface e navegação.
Não armazenam dados nem realizam autenticação.

- Google Material Icons.
